Das eCarUp Backend besteht aus einer [kostenlosen Lade-App](https://web.ecarup.com/elektroauto-lade-app/) und einem Webportal. Der Stationsbetreiber entscheidet selbst, wer, wann und zu welchem Preis an seiner Ladestation laden kann. Eine Liste aller kompatiblen Ladestationen findest du auf unserer Webseite unter [E-Ladestationen](https://web.ecarup.com/e-ladestationen/).
