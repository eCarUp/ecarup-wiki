Le backend eCarUp se compose d'une [application de recharge gratuite](https://web.ecarup.com/elektroauto-lade-app/) et d'un portail web. L'exploitant de la borne décide lui-même qui peut recharger à sa borne de recharge, quand et à quel prix. Vous trouverez une liste de toutes les bornes de recharge compatibles sur notre site web sous [E-Ladestationen](https://web.ecarup.com/e-ladestationen/).
